                                     ### CURSO GIT
        
                                ##Git Software control de versiones
    Git es un software de control de versiones de software, dentro del proyecto para registrar de archivos,
    o conjunto de archivos a lo largo del tiempo, nos servira para recuperar versiones especificas mas adelante.

                                     ##Git VS otros CVS
    La principal diferencia entre Git y cualquier CVS es la forma en que maneja sus datos , Conceptualmente
    la mayoria de los otros sistemas almacenan su informacion como una lista de cambios.
    Git maneja su datos como un conjunto de copias instantaneas de un sistema de archivos miniatura.
    Cada vez que se confirma un cambio, o guardas el estado de tu proyecto en Git, basicamente toma una foto,
    de todos los archivos y guarda referencia a esa copia instantanea. Git maneja sus datos como una secuencia, de copias instantaneas.
